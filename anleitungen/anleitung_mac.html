Schreibweise in dieser Anleitung

Menüs, Schaltflächen und Felder stehen so, wie sie in der deutschsprachigen QGIS-Oberfläche erscheinen, hervorgehoben als Bezeichnung. QGIS verwendet deutsches Deutsch, daher erscheinen dort teilweise «ß» (z. B. Schließen). Ein Pfeil → bedeutet «danach anklicken». Adressen (URLs) in den grauen Kästen genau so abtippen oder kopieren – ohne Leerzeichen.

Mac-Tasten: ⌘ = Befehlstaste (cmd) · ⇧ = Umschalttaste (Shift) · ⌥ = Wahltaste (alt/option) · ⌃ = Control (ctrl). «Rechtsklick» bedeutet auf dem Mac: mit zwei Fingern auf das Trackpad klicken oder ⌃ gedrückt halten und klicken. Die Menüleiste von QGIS steht nicht im Programmfenster, sondern ganz oben am Bildschirmrand (Kap. 4.2).

Teil A · Grundlagen

1Was öffentlich ist – und was nicht

Mit QGIS lässt sich tatsächlich einsehen, was auf fremden Feldern angebaut wird. Grundlage ist keine Spezialfunktion von QGIS, sondern amtliche Geodaten, die die Kantone öffentlich bereitstellen. QGIS ist das Werkzeug, um diese Daten anzuzeigen und auszuwerten.

1.1Herkunft der Daten

Landwirtschaftsbetriebe deklarieren jedes Jahr ihre Flächen und Kulturen im kantonalen Agrarinformationssystem. Diese Angaben dienen dem Vollzug des Landwirtschaftsgesetzes, insbesondere der Berechnung der Direktzahlungen, sowie der Agrarstatistik. Die Kantone erfassen daraus den Geobasisdatensatz «Landwirtschaftliche Kulturflächen» (Identifikator 153) nach einem schweizweit einheitlichen Datenmodell und stellen ihn über das interkantonale Portal geodienste.ch bereit.

Die beiden für diese Anleitung wichtigen Teildatensätze – Nutzungsflächen (153.1) und Bewirtschaftungseinheiten (153.6) – sind im Datenmodell der Zugangsberechtigungsstufe A zugeordnet, das heisst öffentlich zugänglich.

Teil B · Installation und Einrichtung auf dem Mac

3QGIS auf dem Mac installieren

3.1Die richtige Version wählen

Auf qgis.org stehen zwei Versionen zur Auswahl (Stand 28.09.2026):

VersionNummerZweck
Long Term Release (LTR)3.44.14Empfohlen. Auf Stabilität ausgelegt. qgis.org empfiehlt die LTR, wenn unklar ist, welche Version passt.
Latest Release4.2.2Neueste Funktionen (erschienen am 28.08.2026), häufigere Änderungen.

Diese Anleitung ist für die LTR 3.44 geschrieben. QGIS ist kostenlos, wenn es von qgis.org bezogen wird. Andere Download-Seiten sind zu meiden.

Das offizielle Installationspaket für macOS ist signiert und von Apple beglaubigt (notarisiert). Gemäss qgis.org läuft dasselbe Paket auf Macs mit Intel-Prozessor und mit Apple Silicon (M-Chips).

3.2Herunterladen

  1. Safari (oder einen anderen Browser) öffnen und die Adresse qgis.org/download aufrufen.
  2. Es erscheint ein Hinweis zur Spende («Before download starts»). Eine Spende ist freiwillig. Zum Weitergehen auf Skip it and go to download klicken.
  3. Oben ist meist schon Windows ausgewählt. Auf macOS umschalten bzw. zum Abschnitt macOS scrollen.
  4. Auf Long Term Version for macOS (3.44 LTR) klicken. Nicht «Regular Version» oder «Nightly builds» wählen. Die Datei heisst qgis_ltr_final-3_44_14.dmg. Sie ist gross; der Download kann einige Minuten dauern.
  5. Falls Safari fragt, ob Downloads von qgis.org erlaubt werden sollen: Erlauben.

3.3Installieren

  1. Im Finder den Ordner Downloads öffnen (oder im Dock auf den Downloads-Stapel klicken) und die Datei qgis_ltr_final-3_44_14.dmg doppelt anklicken. Das Öffnen des Datenträgerabbilds kann einen Moment dauern.
  2. Es öffnet sich ein Fenster mit dem QGIS-Symbol. Das Symbol mit der Maus in den Ordner Programme (Applications) ziehen. Der Kopiervorgang dauert je nach Mac eine bis mehrere Minuten.
  3. Danach das Datenträgerabbild auswerfen: im Finder in der Seitenleiste neben dem QGIS-Eintrag auf das Auswurfsymbol ⏏ klicken. Die .dmg-Datei im Download-Ordner kann anschliessend in den Papierkorb.

3.4Erster Start

  1. Im Finder den Ordner Programme öffnen und QGIS doppelt anklicken. Alternativ: ⌘ + Leertaste (Spotlight), QGIS eintippen, ↩ drücken.
  2. macOS meldet, dass die App aus dem Internet geladen wurde. Mit Öffnen bestätigen. Diese Rückfrage erscheint nur beim ersten Start.
  3. Der erste Start dauert deutlich länger als spätere Starts. Weitere Rückfragen von macOS (z. B. Zugriff auf die Ordner «Dokumente» oder «Downloads») mit Erlauben beantworten, damit QGIS dort Dateien öffnen und speichern kann.
  4. Empfehlung: Solange QGIS läuft, im Dock mit Rechtsklick auf das QGIS-Symbol → Optionen → Im Dock behalten wählen. So lässt sich QGIS künftig mit einem Klick starten.
Falls macOS das Öffnen verweigert

Erscheint statt Öffnen nur OK oder In den Papierkorb legen: OK wählen, dann oben links auf das Apfel-Symbol → Systemeinstellungen → Datenschutz & Sicherheit → ganz nach unten scrollen → bei der Meldung zu QGIS Dennoch öffnen klicken und mit dem Mac-Passwort bestätigen. Bei älteren macOS-Versionen heisst der Bereich «Sicherheit».

3.5Sprache auf Deutsch stellen (falls nötig)

QGIS übernimmt die Sprache von macOS. Erscheint die Oberfläche englisch:

  1. In der Menüleiste oben am Bildschirm Settings → Options… wählen (gleichwertig: QGIS → Preferences…, Tastenkürzel ⌘ + ,). Im Fenster links General anklicken.
  2. Häkchen bei Override System Locale setzen und bei User interface translation Deutsch wählen.
  3. OK klicken, QGIS mit ⌘ + Q beenden und neu starten.

Auf Deutsch heisst der Weg: Einstellungen → Optionen… → Allgemein → System-Locale übersteuern. Dieselben Optionen öffnen sich auch über das Programm-Menü QGIS (oben links, direkt rechts neben dem Apfel-Symbol).

Zoomen mit zwei Fingern reagiert oft sehr empfindlich. Für kontrollierte Schritte die Lupen-Symbole Hineinzoomen / Hinaus zoomen in der Werkzeugleiste verwenden oder mit dem Lupen-Werkzeug einen Rahmen um das gewünschte Gebiet ziehen. Kontextmenüs erscheinen nicht? Apfel-Symbol oben links → Systemeinstellungen → Trackpad die Option Sekundärklick einschalten.

5Erweiterung «Swiss Locator» installieren

Swiss Locator ist eine kostenlose QGIS-Erweiterung von OPENGIS.ch, finanziert von der QGIS-Anwendergruppe Schweiz. Sie ergänzt das Suchfeld um Schweizer Orte und Adressen aus dem Geoportal des Bundes. Zusätzlich lassen sich damit Layer des Bundes und Ressourcen von opendata.swiss suchen sowie vorbereitete Hintergrundkarten laden.

  1. Einmal ins QGIS-Fenster klicken. Dann oben in der Menüleiste des Bildschirms Erweiterungen → Erweiterungen verwalten und installieren… wählen.
  2. Links Alle wählen und oben ins Suchfeld Swiss Locator eintippen.
  3. Den Eintrag «Swiss Locator» anklicken → unten rechts Erweiterung installieren → nach der Meldung Schließen.
  4. Test: Unten links ins Suchfeld Suchmuster (⌘K) einen Ortsnamen tippen, z. B. Schwerzenbach, und einen Treffer anklicken. Die Karte springt dorthin.
Alternative, falls das Menü nicht gefunden wird

Ins Suchfeld unten links (⌘+K) Erweiterungen eintippen und den Treffer Erweiterungen verwalten und installieren… anklicken.

Tipp

Mit dem Kürzel chb im Suchfeld listet Swiss Locator fertig gestaltete Schweizer Hintergrundkarten (Vektorkacheln) auf. Als Alternative zu Kapitel 6 lassen sich diese per Klick laden.

Teil C · Daten laden

6Hintergrundkarten von swisstopo

Als Orientierung dienen das Luftbild SWISSIMAGE und die farbige Landeskarte. Es gibt zwei Wege. Weg A ist der schnellere; Weg B kommt ohne Sonderzeichen aus und ist die Reserve, falls Weg A nicht klappt.

Wichtig: zuerst auf die Schweiz zoomen

Nach dem Hinzufügen einer Hintergrundkarte zeigt QGIS meist die ganze Welt oder einen zufälligen Ausschnitt. Das swisstopo-Luftbild deckt nur die Schweiz ab, alles andere bleibt weiss. Der Layer ist dann korrekt geladen, nur der Ausschnitt stimmt nicht. Darum als Erstes im Suchfeld unten links (Swiss Locator, Kap. 5) einen Ort tippen, z. B. Schwerzenbach, und den Treffer anklicken.

6.1Weg A: als XYZ-Kacheln (empfohlen)

  1. Im Bedienfeld Browser (links oben) den Eintrag XYZ-Kacheln suchen. Dort steht bereits OpenStreetMap. Mit Rechtsklick (zwei Finger bzw. ⌃-Klick) auf XYZ-Kacheln klicken → Neue Verbindung…
  2. Bei Name eintragen: swisstopo Luftbild. Bei URL genau diese Adresse in einer Zeile eintragen:
    URL Luftbild (SWISSIMAGE) – eine Zeile, keine Leerzeichenhttps://wmts.geo.admin.ch/1.0.0/ch.swisstopo.swissimage/default/current/3857/{z}/{x}/{y}.jpeg
    Alle übrigen Felder unverändert lassen → OK.
  3. Schritt 1 und 2 wiederholen mit Name swisstopo Landeskarte und dieser URL:
    URL Landeskarte farbig – eine Zeile, keine Leerzeichenhttps://wmts.geo.admin.ch/1.0.0/ch.swisstopo.pixelkarte-farbe/default/current/3857/{z}/{x}/{y}.jpeg
  4. Im Browser auf das kleine Dreieck vor XYZ-Kacheln klicken und swisstopo Luftbild doppelt anklicken. Der Layer erscheint im Bedienfeld Layer.
  5. Ins Suchfeld unten links einen Ort tippen (z. B. Schwerzenbach) und den Treffer anklicken. Jetzt erscheint das Luftbild. Danach mit zwei Fingern auf dem Trackpad (bzw. mit dem Mausrad) weiterzoomen.
Im Bedienfeld Layer steht «swisstopo Luftbild», und nach der Ortssuche ist das Luftbild sichtbar. Bleibt die Karte trotz Ortssuche weiss: Kapitel 19 (Fehlerbehebung).
Zu den geschweiften Klammern

Die Zeichen {z}/{x}/{y} sind Platzhalter, die QGIS beim Laden ersetzt. Sie gehören genau so in die Adresse (Mac-Tastatur: ⌥+8 für { und ⌥+9 für }). Beim Kopieren aus diesem PDF kann ein Zeilenumbruch oder Leerzeichen mitkommen. Nach dem Einfügen prüfen, dass die Adresse aus einer durchgehenden Zeile besteht und mit .jpeg endet.

6.2Weg B: als WMS vom Geoportal des Bundes (ohne Sonderzeichen)

  1. Menü Layer → Layer hinzufügen → WMS/WMTS-Layer hinzufügen… → Neu.
  2. Name: Geoportal Bund. URL:
    URL WMS Geoportal des Bundeshttps://wms.geo.admin.ch/
    → OK → Verbinden. Der Dienst enthält über 2000 Layer; das Laden der Liste dauert einige Sekunden.
  3. Ins Suchfeld über der Liste swissimage tippen. Die Zeile SWISSIMAGE Hintergrund (ch.swisstopo.swissimage) anklicken → Hinzufügen.
  4. Für die Landeskarte im Suchfeld Landeskarten tippen und Landeskarten (farbig) (ch.swisstopo.pixelkarte-farbe) hinzufügen → Schließen.
  5. Wie bei Weg A: im Suchfeld unten links einen Ort suchen, damit die Karte auf die Schweiz springt.

Der WMS des Bundes liefert die Bilder direkt in Landeskoordinaten (EPSG:2056) und bietet daneben viele weitere Karten, z. B. die Bodeneignungskarte (Kap. 16.3). Bei Verwendung in Karten ist die Quelle anzugeben («© swisstopo»).

7Koordinatensystem LV95 einstellen

QGIS übernimmt beim ersten geladenen Layer dessen Koordinatensystem. Die XYZ-Kacheln aus Weg A verwenden das weltweite System EPSG:3857. Für korrekte Flächen und Distanzen in Metern wird das Projekt auf die Schweizer Landeskoordinaten umgestellt:

  1. Unten rechts in der Statusleiste auf die Schaltfläche mit der Angabe EPSG:3857 (bei Weg B steht dort bereits EPSG:2056 oder ein anderer Code) klicken. Das Fenster Projekteigenschaften öffnet sich im Bereich KBS.
  2. Ins Feld Filter die Zahl 2056 eintippen.
  3. In der Liste darunter CH1903+ / LV95 (EPSG:2056) anklicken → OK.
Unten rechts steht nun «EPSG:2056». Die Karte sieht gleich aus, ist aber auf Landeskoordinaten umgestellt.

8Nutzungsflächen als Karte anzeigen (WMS)

Der schnellste Weg, um zu sehen, was auf den Feldern wächst: ein fertiges Kartenbild vom Server, bei dem sich jede Fläche anklicken lässt.

  1. Zuerst auf das interessierende Gebiet zoomen (z. B. eine Gemeinde über das Suchfeld).
  2. Menü Layer → Layer hinzufügen → WMS/WMTS-Layer hinzufügen…
  3. Auf Neu klicken. Name: Nutzungsflächen WMS. URL:
    URL Nutzungsflächen (WMS und WFS)https://geodienste.ch/db/lwb_nutzungsflaechen_v2_0_0/deu
    Alle übrigen Einstellungen unverändert lassen → OK.
  4. Auf Verbinden klicken. Es erscheint eine Liste der verfügbaren Layer.
  5. Die Zeile mit dem Namen nutzungsflaechen anklicken → Hinzufügen → Schließen.
  6. Damit das Luftbild durchscheint: Rechtsklick auf den neuen Layer → Schieberegler Deckkraft auf etwa 60 % stellen.
Die landwirtschaftlichen Flächen erscheinen farbig über dem Luftbild. Falls nichts zu sehen ist: weiter hineinzoomen.

8.1Eine Fläche abfragen

  1. In der Werkzeugleiste das Werkzeug Objekte abfragen wählen (Symbol mit «i» und Mauszeiger, ⌘+⇧+I).
  2. Im Bedienfeld Layer den Layer nutzungsflaechen markieren und dann auf eine Fläche in der Karte klicken.
  3. Das Fenster Identifikationsergebnis zeigt die Angaben, u. a. nutzung (Kultur im Klartext), lnf_code, flaeche_m2 und bezugsjahr.
Weitere Darstellungen im selben Dienst

Neben nutzungsflaechen bietet der Dienst die Layer nutzungsflaechen_hauptkategorien und nutzungsflaechen_bff_q1 (Biodiversitätsförderflächen Qualitätsstufe I) an.

Grenze des WMS

Ein WMS liefert nur ein Bild. Einfärben nach eigenen Regeln, Auswählen, Summieren und Exportieren sind damit nicht möglich. Dafür dient der WFS in Kapitel 9.

9Nutzungsflächen als Vektordaten laden (WFS)

Über denselben Dienst lassen sich die Flächen auch als echte Vektordaten laden – mit allen Attributen.

  1. Karte auf das gewünschte Gebiet zoomen (sinnvoll: einige Kilometer Ausschnitt, z. B. eine Gemeinde).
  2. Menü Layer → Datenquellenverwaltung (⌘+L) → links WFS / OGC API - Features wählen.
  3. Auf Neu klicken. Name: Nutzungsflächen WFS. URL (dieselbe wie beim WMS):
    URL Nutzungsflächenhttps://geodienste.ch/db/lwb_nutzungsflaechen_v2_0_0/deu
    Version auf Maximum belassen → OK.
  4. Auf Verbinden klicken und in der Liste den Eintrag nutzungsflaechen anklicken.
  5. Wichtig: unten das Häkchen bei Nur Objekte laden, die sich mit dem Kartenausschnitt überschneiden setzen.
  6. Hinzufügen → Schließen.
Achtung

Ohne das Häkchen aus Schritt 5 lädt QGIS den gesamten Datensatz aller Kantone. Das dauert sehr lange und kann QGIS blockieren. In diesem Fall den Layer entfernen (Rechtsklick → Layer löschen…) und mit Häkchen neu hinzufügen. Wird später ein anderes Gebiet angezeigt, lädt QGIS die dortigen Flächen automatisch nach.

Die Flächen erscheinen als einheitlich gefärbte Polygone. Die Einfärbung nach Kultur folgt in Kapitel 10. Stand 28.09.2026 liefert der Dienst für Zürich das Bezugsjahr 2025.

9.1Die Attributtabelle

Rechtsklick auf den Layer → Attributtabelle öffnen (oder fn+F6). Jede Zeile ist eine Fläche. Die Tabelle enthält die im aktuellen Ausschnitt geladenen Flächen.

10Einfärben, auswählen, summieren, filtern

Alle Schritte in diesem Kapitel beziehen sich auf den WFS-Layer nutzungsflaechen aus Kapitel 9.

10.1Flächen nach Kultur einfärben

  1. Doppelklick auf den Layer im Bedienfeld Layer. Das Fenster Layereigenschaften öffnet sich.
  2. Links Symbolisierung wählen.
  3. Ganz oben die Auswahl Einzelsymbol auf Kategorisiert umstellen.
  4. Bei Wert das Feld nutzung wählen.
  5. Unten auf Klassifizieren klicken → OK.
Jede Kultur hat eine eigene Farbe; die Legende erscheint im Bedienfeld Layer unter dem Layer.

Einzelne Kulturen lassen sich über die Häkchen in der Legende aus- und einblenden. Farben ändern: Doppelklick auf das Farbfeld in der Kategorienliste.

10.2Bestimmte Kulturen auswählen

  1. Layer im Bedienfeld Layer markieren. Menü Bearbeiten → Auswählen → Objekte nach Ausdruck wählen…
  2. Ins linke Textfeld eintragen (Beispiel: Freilandgemüse inkl. Konservengemüse):
    Ausdruck"lnf_code" IN (545, 546)
  3. Objekte wählen → Schließen. Die gewählten Flächen erscheinen gelb hervorgehoben.

Weitere Beispiele: "lnf_code" = 524 (Kartoffeln) · "flaeche_m2" > 10000 (Flächen über 1 ha) · "nutzung" ILIKE '%gemüse%' (alle Nutzungen mit «gemüse» im Namen). Feldnamen stehen in doppelten, Texte in einfachen Anführungszeichen.

10.3Gewählte Flächen zählen und summieren

  1. Menü Ansicht → Statistische Zusammenfassung (alternativ das Σ-Symbol in der Werkzeugleiste). Das Bedienfeld Statistik öffnet sich.
  2. Oben den Layer nutzungsflaechen und das Feld flaeche_m2 wählen.
  3. Häkchen bei Nur gewählte Objekte setzen. Die Zeile Summe zeigt die Gesamtfläche in m², Anzahl die Zahl der Flächen.

In der Attributtabelle zeigt die Auswahl unten links Gewählte Objekte anzeigen nur die gewählten Zeilen.

10.4Nur bestimmte Kulturen anzeigen (Filter)

  1. Rechtsklick auf den Layer → Filter…
  2. Unten im Textfeld den Ausdruck eintragen, z. B. "lnf_code" IN (545, 546) → OK.
  3. Die Karte zeigt nur noch diese Flächen; neben dem Layernamen erscheint ein Filtersymbol. Zum Aufheben den Filter erneut öffnen, das Textfeld leeren und OK klicken.

10.5Beschriftung anzeigen

  1. Doppelklick auf den Layer → links Beschriftungen.
  2. Oben Einzelne Beschriftungen wählen und bei Wert das Feld nutzung (oder lnf_code für kürzere Texte) einstellen → OK.

12.1Parzellengrenzen (Amtliche Vermessung)

12.2Eigentümer abfragen

Eigentümernamen sind in keinem der obigen Layer enthalten. Nach Art. 970 Abs. 2 ZGB darf jede Person ohne Nachweis eines Interesses Auskunft über den Namen der Eigentümerin oder des Eigentümers eines Grundstücks erhalten. Der Kanton Zürich bietet dafür eine Online-Auskunft:

  1. Im Browser geo.zh.ch öffnen und den GIS-Browser mit der Karte Eigentumsauskunft aufrufen.
  2. Das Grundstück in der Karte anklicken.
  3. Eine Schweizer Mobiltelefonnummer angeben und den per SMS erhaltenen Code eingeben (5 Minuten gültig).
  4. Angezeigt werden Name und Vorname bzw. Firma, die zuletzt bekannte Wohnadresse und die Eigentumsform.
Regeln der Eigentumsauskunft

Maximal fünf Abfragen pro Tag. Abfragen nur grundstücksbezogen – eine Suche nach Personen ist nicht gestattet, Serienabfragen sind unzulässig. Die Abfrage ist gebührenfrei. Eigentümerinnen und Eigentümer können ihre Daten für die Online-Auskunft sperren lassen; dann bleibt die Auskunft beim zuständigen Notariat (Grundbuchamt).

13Messen und eigene Flächen zeichnen

13.1Messen

In der Werkzeugleiste das Lineal-Symbol öffnen und Linie messen oder Fläche messen wählen. Punkte per Klick setzen, Rechtsklick (zwei Finger bzw. ⌃-Klick) beendet die Messung. Mit Projekt-KBS EPSG:2056 (Kap. 7) sind die Werte in Metern bzw. Quadratmetern.

  1. Menü Layer → Layer erstellen → Neuer GeoPackage-Layer…
  2. Datenbank: über die Schaltfläche … öffnet sich ein Finder-Fenster. Ordner wählen (z. B. «Dokumente»), Dateiname eingeben, z. B. eigene_felder.gpkg, und bestätigen.
  3. Tabellenname: felder · Geometrietyp: Polygon · KBS: EPSG:2056 – CH1903+ / LV95.
  4. Unter Neues Feld: Name name, Typ Text → Zur Feldliste hinzufügen. Bei Bedarf weitere Felder (z. B. kultur) auf dieselbe Weise.
  5. OK. Der leere Layer erscheint im Bedienfeld Layer.

13.3Fläche zeichnen

  1. Den neuen Layer markieren und Bearbeitungsstatus umschalten (Stift-Symbol) anklicken.
  2. Polygonobjekt hinzufügen wählen. Die Eckpunkte der Fläche nacheinander per Klick setzen; ein Rechtsklick (zwei Finger bzw. ⌃-Klick) schliesst die Fläche ab.
  3. Im erscheinenden Formular die Attribute (z. B. Name) eintragen → OK.
  4. Layeränderungen speichern klicken und den Bearbeitungsmodus mit dem Stift-Symbol beenden.

17Grenzen der Daten

  • Zeitverzug: Publiziert wird der definitive Stand nach der jährlichen Erhebung. Im Herbst 2026 zeigen die Daten den Stand der Publikation vom 09.01.2026; massgebend ist das Feld bezugsjahr. Die aktuelle Saison ist nicht enthalten.
  • Grobe Kategorien: Deklariert wird die Nutzung gemäss Katalog, z. B. «Einjährige Freilandgemüse». Einzelne Gemüsearten, Sätze, Sorten und Termine sind nicht ersichtlich.
  • Deklaration: Die Daten beruhen auf den Angaben der Betriebe und können von der tatsächlichen Nutzung abweichen.
  • Vollständigkeit: Enthalten sind die im kantonalen Agrarinformationssystem erfassten Flächen, auch nicht beitragsberechtigte (Feld beitragsberechtigt). Flächen ausserhalb dieses Systems, z. B. Hobbyflächen, fehlen.
  • Bewirtschafter ≠ Eigentümer: Die Bewirtschaftungseinheiten zeigen, wer eine Fläche bewirtschaftet, nicht wem sie gehört.
  • Modellwechsel: Die Kantone stellen bis spätestens 31.01.2027 auf Modellversion 3.0 um. Der Dienst in Version 2.0 enthält auch die Kantone, die bereits umgestellt haben (automatische Rückumwandlung). Falls die Adressen aus dieser Anleitung künftig nicht mehr funktionieren, auf geodienste.ch die aktuelle Adresse nachschlagen (Endung _v3_0_0).
